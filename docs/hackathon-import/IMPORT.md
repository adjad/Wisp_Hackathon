# Wisp hackathon repository import

This repository imports the tracked Wisp source at commit `ed361c0c3b2bce2bd8daf7242b805e3894572f7a` from [adjad/wisp](https://github.com/adjad/wisp), retaining its Git history. The import merge also retains this repository's initial commit `34ea5fd431edd18a42a17138661ac45c0a6328fb` as an ancestor.

Wisp's source README remains at the repository root. The initial hackathon README is preserved byte for byte in [INITIAL_REPOSITORY_README.md](INITIAL_REPOSITORY_README.md). This repository's existing root `LICENSE` is retained unchanged. No license file was removed.

This commit is the baseline import only. Catch, Mac workflow improvements and the iPhone port are separate draft integration work. Their publication does not establish release readiness or transfer validation results to a new combined commit. Product tests, model inference, native execution, installation and release were not performed for this import.

Only tracked source and its commit history were imported. Local working-tree changes, private runtime state, debug-log downloads, local model files and unpublished paused routing proposals were not copied. The original Wisp repository was not changed.
